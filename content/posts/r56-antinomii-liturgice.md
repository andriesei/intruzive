Cât de înălțătoare este sobrietatea și solemnitatea! Cât de împlinitoare este tânguirea și plânsul! Ce plină de slavă este batjocora! Cât de înțelepțitoare este nebunia! Cât de divin este diabolicul! (Iată aici două fețe!)
