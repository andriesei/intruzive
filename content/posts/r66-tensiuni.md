Moartea? E un strigăt! Este strigătul neauzit. Este strigătul substanței. Este răzvrătire. Este elogiul non‑substanței și non‑formei. Este o psaltire a non‑ființării. E mai mult decât război și sânge! Este mai mult decât identitate! Este o dezrădăcinare. Este plânset și groază. Este durere și frică. Frica doare și mai mult decât atât. Este dorința de (potențare spre) dezintegrare în vid, nu vidul plin de energie, ci unul plin de absență. E neputința de a transfigura lumea. Este criză și dărâmare! Este detonare… da! Detonarea este cuvântul potrivit. E mai mult decât disperare și angoasă. Este sângele nevăzut. Este dor de non‑existență. Este semnătura pe care noi am iscălit‑o pe contractul morții, acceptând toate clauzele contractuale ale conștiinței. Este zgomot mut… slăbiciunea morții este viața. Dar este frica de vulnerabilitate slăbiciunea vieții?
